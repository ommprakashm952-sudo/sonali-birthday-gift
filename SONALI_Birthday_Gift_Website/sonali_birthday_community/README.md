# SONALI — Birthday Digital Gift Website

A personal shareable birthday gift page focused only on Sonali. No accounts, login, quizzes, polls, comments, or social feed. Includes the five provided photos, animated page, photo lightbox, heartfelt letter, birthday shayari, and live age-counter support.

## Run on Windows
1. Extract the ZIP.
2. Ensure Python 3.10+ is installed.
3. Double-click `RUN_SONALI.bat`. First run installs dependencies (internet required).
4. Open http://127.0.0.1:5000 and keep the terminal open.

## Set birth date for the live counter
Set `SONALI_BIRTH_DATE=YYYY-MM-DD` and optionally `SONALI_BIRTH_TIME=HH:MM` in the environment before starting the app. Counter uses India Standard Time. Do not guess the date.

## Public access
The ZIP runs locally by default. It does not create a public URL. To share it online, deploy to a Python-compatible host with HTTPS and Gunicorn. Check the host's current free-tier and storage limitations.
